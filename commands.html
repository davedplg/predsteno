# Commands In the third input step there is a semi-colon. Instead of typing over it to enter a missing word, here are some commands that can be used. ## Move - ;gg move to top - ;20g move to line 20 - ;ng move to line n ## Deletion - ;dd delete current line - ;3d delete 3 lines - ;nd delete n lines - ;dgg delete to top ## Copy - ;yy copy current line - ;5y copy 5 lines - ;ny copy n lines ## Paste - ;p paste below - ;P paste above
